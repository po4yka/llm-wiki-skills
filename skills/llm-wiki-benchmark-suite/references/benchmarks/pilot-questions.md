# LLM-Wiki pilot questions

Use 10-20 real questions from the user's work. This starter set can be adapted.

## Question categories

1. Factual lookup from one source.
2. Synthesis across multiple sources.
3. Decision provenance: why was something decided?
4. Context recovery: where did the user/team stop?
5. Stale/current claim check.
6. Contradiction discovery.
7. Output generation: memo, PRD, plan, report or issue.
8. Query that should be saved back into the wiki.

## Starter questions

- What are the three most important claims in this source set?
- Which existing wiki pages are relevant to this new source?
- What decision did we make about the retrieval stack and why?
- Which claims are stale or unsupported?
- What should be filed back into `wiki/queries/`?
- What would a new team member need to read first?
- What source evidence supports the main recommendation?
- Which pages should be merged, split or archived?
