# Domain packs

Domain packs adapt the generic LLM-Wiki pattern to concrete use cases.

| Pack | Use case |
|---|---|
| `personal-second-brain` | Personal research, notes and durable synthesis. |
| `codebase-docs` | Agent-readable repository documentation. |
| `research-papers` | Literature review and paper synthesis. |
| `team-onboarding` | Team knowledge, onboarding and bus factor reduction. |
| `startup-market-research` | Market maps, competitors, insights and strategy. |
| `competitive-intelligence` | External landscape tracking and source refresh. |

Use `llm-wiki-domain-pack` to customize these packs for a user's domain.
