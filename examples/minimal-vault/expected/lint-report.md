# Expected lint report contract

## Summary

The report should be safe to review and should not auto-resolve truth conflicts.

## Required sections

- `## Summary`
- `## Critical issues`
- `## High-priority review queue`
- `## Broken links`
- `## Orphans`
- `## Provenance gaps`
- `## Stale pages`
- `## Contradictions`
- `## Taxonomy drift`
- `## Suggested patches`
- `## Metrics`

## Safety expectation

The report may propose patches, but should not silently edit source or synthesis pages.
