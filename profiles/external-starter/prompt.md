# External starter bootstrap prompt

Copy the text below into an Agent Skills-compatible coding agent.

```text
Set up the supported LLM-Wiki external starter profile in the current project.

1. Inspect the current directory, repository instructions and git status. Preserve all existing work.
2. Run `npx llm-wiki-starter init .`. If agent detection fails, retry once with your Agent Skills ID, for example `--agent codex` or `--agent claude-code`.
3. Read the installed `llm-wiki-zero-to-working-wiki` and `llm-wiki-setup` instructions. Do not install more skills or the full pack unless I ask.
4. Use the sample source only when there is no better trusted source. Complete one ingest, one reusable query and one lint report. Keep generated wiki pages as drafts.
5. Do not send private content to cloud services. Do not publish anything.
6. Finish with installed skills, changed files, checks and observed results, review-required items and the next useful action.
```
